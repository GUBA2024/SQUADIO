# المستشار إسلام الغرياني — Premium Law Firm Website

موقع عربي احترافي RTL لمكتب **المستشار إسلام الغرياني** بتصميم فاخر (Dark Blue / Gold) مع تأثيرات ثلاثية الأبعاد.

## المميزات الرئيسية

- Hero Section مع مشهد **3D Justice Scale** باستخدام Three.js.
- تصميم Glassmorphism فاخر مع دعم **Dark/Light mode**.
- أقسام قانونية كاملة:
  - من نحن
  - نبذة عن القانون المصري
  - الخدمات القانونية
  - لماذا تختارنا (Counters + Timeline)
  - مقالات قانونية
  - آراء العملاء (Slider)
  - FAQ
  - تواصل معنا + WhatsApp + اتصال مباشر + Google Maps
- SEO metadata + Structured Data (`LegalService`).
- متجاوب بالكامل مع جميع الأجهزة.

## التشغيل المحلي

### فتح مباشر
```bash
xdg-open index.html
```

### أو عبر سيرفر محلي
```bash
python3 -m http.server 8000
```
ثم افتح:
`http://localhost:8000`

## الملاحظات

- يتم تحميل `Three.js` و `GSAP` عبر CDN داخل `index.html`.
- حدّث روابط التواصل، رقم الهاتف، ورابط الدومين الفعلي (`canonical`) قبل النشر.
